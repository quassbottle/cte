# EGTS 2022 Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить полный повторяемый импорт доступных на osu! wiki данных одиночного турнира EGTS 2022.

**Architecture:** Чистый parser преобразует официальный Markdown в типизированные структуры без I/O. Отдельный Nest CLI загружает Markdown, валидирует полноту, транзакционно пересоздаёт турнир и после коммита синхронизирует все доступные osu! multiplayer rooms.

**Tech Stack:** TypeScript, Bun test, NestJS application context, Drizzle ORM, PostgreSQL, native `fetch`.

## Global Constraints

- Источник: `https://raw.githubusercontent.com/ppy/osu-wiki/master/wiki/Tournaments/GTS/EGTS_2022/en.md`.
- Турнир: `mode: taiko`, `isTeam: false`, закрытая регистрация.
- Импортировать всех доступных участников, поддерживаемый staff, девять стадий, девять маппулов, все матчи и все доступные osu! rooms.
- Не выдумывать отсутствующие qualifier lobby links/results и VOD.
- Исправить окончание Round of 32 на `2022-09-04`.
- Не добавлять зависимости и не создавать общий framework импорта.
- Не перезаписывать административные роли существующих пользователей.

- [ ] **Step 3: Implement the minimal parser**

Define:

```ts
export type EgtsUser = {
  osuId: number;
  osuUsername: string;
  countryCode: string;
};

export type EgtsStaffRole =
  | 'Host'
  | 'Mapper'
  | 'Playtester'
  | 'Referee'
  | 'Streamer'
  | 'Commentator';

export type EgtsParticipant = EgtsUser & { seedGroup: string };
export type EgtsStaff = EgtsUser & { role: EgtsStaffRole };

export type EgtsMatch = {
  stageName: string;
  player1Name: string;
  player2Name: string;
  startsAt: string;
  osuMatchId: number | null;
  isWalkover: boolean;
  index: number;
};

export type EgtsMappoolBeatmap = {
  stageName: string;
  osuBeatmapsetId: number;
  osuBeatmapId: number;
  label: string;
  mod: string;
  index: number;
};
```

Переиспользовать простые локальные helpers `clean`, `section`, `cells`, `usersFrom` из TWC-парсера. Отличия EGTS:
