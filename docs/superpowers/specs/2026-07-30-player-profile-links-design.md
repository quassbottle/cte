# Аватары и ссылки на профили игроков

## Цель

Сделать игроков узнаваемыми и кликабельными в статистике solo-турниров и в модалках multiplayer history.

## Статистика турнира

`StageStatisticsService` возвращает `avatarUrl` для player-view competitors. Поле опционально в DTO, потому что team-view competitors не являются пользователями.

В `StatisticsTab` строка игрока показывает компактный круглый Avatar с fallback-инициалами. Для solo-турнира и player view командного турнира аватар и имя ведут на внутренний профиль `/users/{competitor.id}`. Название команды остаётся некликабельной подписью.

В team view поведение названия команды не меняется.

## Multiplayer history

`PlayerMultiplayerScoreData.userId` уже содержит ID внутреннего пользователя либо `null`. В `playerMultiplayerScore.svelte` аватар и имя становятся одной ссылкой `/users/{score.userId}`, когда ID присутствует.

Несопоставленный osu! score с `userId = null` продолжает отображаться без ссылки.

## Доступность и визуальное поведение

- Ссылки используют обычную навигацию SvelteKit и доступны с клавиатуры.
- Аватар получает осмысленный `alt`.
- Имя подчёркивается при hover/focus; существующая компоновка и моды не меняются.
- Новые зависимости и новый общий компонент не добавляются.

## Проверка

- Backend-тест фиксирует `avatarUrl` в player statistics.
- Frontend unit-тест фиксирует формирование внутренней ссылки только при наличии `userId`.
- Запускаются релевантные тесты, backend TypeScript check и frontend check.
- После изменений выполняется `graphify update .`.
